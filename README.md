# Insper Code - Apostilas

Este repositorio usa MkDocs para publicar as apostilas da Insper Code.

## Rodando localmente

Instale as dependencias:

```powershell
python -m pip install -r requirements.txt
```

Abra o servidor local:

```powershell
python -m mkdocs serve
```

Para gerar o site estatico:

```powershell
python -m mkdocs build
```
