    Apostilas Insper Code Jr.¶

    Bem-vindo ao material didático do Insper Code Jr.! Estas apostilas foram pensadas para apoiar os encontros práticos do semestre, com explicações curtas, exercícios guiados e espaço para que cada estudante construa algo funcionando ao longo da aula.

    Como usar este material

    Leia a seção do encontro antes da atividade, acompanhe o roteiro durante a oficina e volte aos exemplos depois para revisar conceitos ou terminar exercícios pendentes.

    Nosso jeito de aprender¶

    A Insper Code Jr. trabalha com aprendizado ativo: em vez de separar teoria e prática, cada encontro apresenta um conteúdo que pode ser aplicado diretamente no seu projeto ao longo do semestre.

    Primeiro encontro: preparação¶

    O primeiro encontro organiza o ponto de partida da turma. O objetivo é alinhar o ambiente de trabalho, apresentar o formato das oficinas e garantir que todos consigam rodar um primeiro projeto localmente.

    Objetivos¶

    Ao fim deste encontro, você deve conseguir:

    • [x] Explicar como as apostilas serão usadas durante o semestre.
    • [x] Abrir um terminal e navegar pelas pastas do projeto.
    • [x] Verificar se as ferramentas básicas estão instaladas.
    Ferramentas básicas — o que preciso ter instalado?
    • Git — controle de versão
    • VS Code (ou editor de sua preferência)
    • Python 3 ou Node.js, dependendo do projeto do encontro
    • Uma conta ativa no GitHub

    Se tiver dúvidas em como instalar algo, procure a diretoria de Tech durante o encontro.
