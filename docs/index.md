# Apostilas Insper Code

Bem-vindo ao material didatico da **Insper Code**. Estas apostilas foram pensadas
para apoiar encontros práticos, com explicações curtas, exercícios guiados e
espaço para que cada estudante construa algo funcionando ao longo da aula.

!!! tip "Como usar este material"
    Leia a seção do encontro antes da atividade, acompanhe o roteiro durante a
    oficina e volte aos exemplos depois para revisar conceitos ou terminar
    exercícios pendentes.

## Nosso jeito de aprender

A Insper Code trabalha com aprendizado ativo. Em vez de separar teoria e
pratica, cada encontro apresenta um conteúdo que pode ser diretamente aplicado nos seus respectivos projetos.

## Primeiro encontro: preparação

O primeiro handout organiza o ponto de partida da turma. O objetivo é alinhar o
ambiente, apresentar o formato das oficinas e garantir que todos consigam rodar
um primeiro projeto localmente.
