# Material Insper Code Jr.

Bem-vindo ao material didático do **Insper Code Jr.**.

**Autoria:** Emily Britto

Este site reúne as informações do semestre, combinados de trabalho e espaços
para as aulas que serão preenchidas pelos professores ao longo das
capacitações.

Use as abas no topo para navegar por:

- **Cronograma**: datas, reuniões, entregáveis e contatos do semestre.
- **Utilidades**: README, commits, branches, pull requests e etiqueta de
  trabalho em repositórios.
- **Aulas**: páginas reservadas para os conteúdos das capacitações.
